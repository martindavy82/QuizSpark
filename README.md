# QuizSpark

QuizSpark is a cross-platform quiz creation and presentation application for schools, churches, youth groups, clubs and events.

## Features:

- Create and manage quizzes;
- Reusable Question Bank;
- Multiple-choice questions;
- Team-based quiz gameplay;
- Question explanations;
- Mystery mode and finale rounds;
- Undo functionality;
- macOS and Windows support.
